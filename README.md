O que são Grafos? 

Grafos são estruturas de dados usadas para representar relações entre elementos. 

Um grafo é composto por: 

Vértices: representam os elementos.  

Arestas: representam as conexões entre os vértices. 

 

Tipos de Grafos 

Grafo Não Direcionado 

As conexões funcionam nos dois sentidos. 

Grafo Direcionado 

As conexões possuem direção. 

Grafo Ponderado 

As arestas possuem pesos (custos, distâncias, tempo etc.). 

 

Algoritmo Escolhido: Busca em Largura (BFS) 

 

Funcionamento 

Começa em um vértice inicial.  

Visita todos os seus vizinhos.  

Depois visita os vizinhos desses vizinhos.  

Continua até percorrer todo o grafo.
